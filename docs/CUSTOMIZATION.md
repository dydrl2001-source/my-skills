# 개인 스킬 커스터마이징 규칙

사용자가 2026-10-20에 이 저장소를 앞으로 만들고 커스터마이징하는 스킬의 보관 장소로 지정했습니다.

## 원본과 배포본

- 원본은 이 저장소의 `.agents/skills/<skill-name>/`에 저장합니다. 기존 `skills/`와 `.claude/`의 자료를 자동 통합하거나 설치하지 않습니다.
- 현재 개인 묶음은 `diagram-design`, `engineering-upgrades`, `video-reader`입니다. 새 스킬을 묶음에 넣을 때는 빌더의 선택 목록과 테스트를 함께 수정합니다.
- Codex 로컬의 `~/.codex/skills`와 플러그인 캐시는 배포된 사본입니다. 캐시를 원본으로 편집하지 않습니다.
- 계정용 비공개 플러그인은 [내 작업 도구](https://chatgpt.com/plugins/plugins_6ad77900d06c8191a674a2837de039b6)이며 ID는 `plugins_6ad77900d06c8191a674a2837de039b6`입니다. 변경 시 기존 ID와 공개 범위를 유지하고 중복 플러그인을 만들지 않습니다.

## 변경 절차

1. 원격 최신 상태, 기존 스킬과 사용자의 요청을 읽고 필요한 범위만 수정합니다. 설명은 한국어로 하고 코드 이름은 저장소 관례를 따릅니다.
2. 실행 코드가 바뀌면 관련 동작을 검증합니다. 지침이 바뀌면 실제 요청 사례로 지침의 적용과 한계를 확인합니다. 단순 복사나 문구 수정에 무관한 테스트를 추가하지 않습니다.
3. 원본 변경과 검증 결과를 커밋합니다. 기존 작업을 덮거나 강제 푸시하지 않습니다.
4. 배포가 필요한 변경은 매니페스트 버전을 올리고 `python scripts/build_plugin.py --output <저장소-밖의-파일.zip>`으로 생성합니다. 검증 후 기존 플러그인 업데이트 도구로 배포합니다.
5. 저장소 커밋과 플러그인 배포 여부를 구분해 보고합니다. GitHub 업로드만으로 플러그인이 바뀌었다고 말하지 않습니다.

## 환경과 데이터

영상 분석은 Python, 셸, 이미지 확인 도구가 필요합니다. 첫 설정은 PyPI, 첫 음성 모델 사용은 Hugging Face, 온라인 영상 수집은 해당 호스트 접근이 필요합니다. 도구가 없는 채팅에서는 실행했다고 말하지 않습니다. Windows 테스트 결과를 Linux 실행 결과로 대신하지 않습니다.

개인 영상, 쿠키, 토큰, 로그인 정보, 전사 결과, 모델 캐시와 가상환경은 커밋하거나 플러그인에 넣지 않습니다. 외부 스킬을 수정하면 원래 라이선스와 출처를 남깁니다. 저장소 공개 범위는 GitHub 설정과 별도이며 이 문서는 공개 범위를 바꾸지 않습니다.
