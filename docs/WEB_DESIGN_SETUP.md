# 웹디자인 도구 사용법

GitHub는 스킬 원본과 변경 이력을 보관합니다. 사용하려는 Codex의 로컬 스킬 폴더나 계정 플러그인에도 배포해야 합니다. 저장소에 올리는 일과 설치·연결은 별도입니다.

## 각 도구의 역할

| 구성 | 역할 | 2026-10-23 이 PC 점검 결과 |
| --- | --- | --- |
| web-design | 목적, 사용자 흐름, 브랜드, 실제 동작을 함께 설계 | 개인 플러그인과 로컬에 있음 |
| emil-design-eng | 컴포넌트 디테일과 애니메이션의 구현·리뷰 기준 | v0.3.0에서 원본과 배포 대상에 추가 |
| Impeccable | 기존 UI의 진단, 접근성, 반응형, 마무리 품질 점검 | 로컬에 있음; 개인 플러그인에 중복 복사하지 않음 |
| Taste Skill v2 (`design-taste-frontend`) | 사이트의 시각 방향과 획일적인 패턴 개선 | 로컬에 v2 있음; 개인 플러그인에 중복 복사하지 않음 |
| apple-design | Apple식 제스처, 스프링, 재질·타이포그래피 | 로컬에 있음; emil-design-eng와 별도 스킬 |
| Figma | 제공한 디자인 파일 읽기·구현 | 현재 대화에 Figma 도구가 제공됨; 파일 권한은 실제 작업 시 확인 |
| 브라우저 도구 | 실제 페이지 조작, 화면 캡처와 시각 확인 | 현재 대화에 브라우저 도구가 제공됨 |

별도의 Playwright MCP는 현재 Codex 설정에 없습니다. 이 대화의 브라우저 도구로 페이지 조작과 캡처를 할 수 있으므로 같은 목적의 서버를 중복 추가하지 않습니다. 다른 실행 환경에 브라우저 도구가 없다면 그 환경에서 별도 연결을 설정해야 합니다. 스킬 설치만으로 Figma 접근 권한이나 브라우저가 생기지는 않습니다.

## 이렇게 요청하면 됩니다

새 페이지:

> 청년부 소개 페이지 만들어줘. web-design과 Taste Skill로 전체 방향을 잡고, emil-design-eng로 버튼·메뉴 동작을 다듬어줘. 완성 후 데스크톱과 모바일 화면을 실제 브라우저에서 확인하고 수정해줘.

기존 화면 개선:

> 이 화면을 Impeccable로 점검하고 emil-design-eng 기준으로 인터랙션을 다듬어줘. 현재 브랜드와 기능을 유지하고, 화면 캡처로 수정 결과를 확인해줘.

Figma 구현:

> 이 Figma 링크를 기준으로 구현해줘: [디자인 링크]. 디자인 파일을 읽고 실제 브라우저 화면과 비교해서 간격·글꼴·반응형 차이를 수정해줘.

구체적인 작업을 함께 말하면 됩니다. 스킬 이름만 보내면 해당 스킬이 작업 설명을 기다릴 수 있습니다. 모든 스킬을 한꺼번에 호출하기보다, 전체 방향과 마무리 점검에 맞춰 필요한 스킬을 사용합니다.

새 로컬 스킬은 설치 후 다음 대화 차례부터 사용할 수 있습니다. 다른 PC나 클라우드에서는 그 환경에도 설치하거나 지원되는 개인 플러그인을 사용해야 합니다. 이 개인 묶음에는 Impeccable·Taste Skill 자체가 포함되지 않으므로 다른 환경에 자동으로 복사되지는 않습니다.

## 원본과 검증

추가한 스킬은 [Emil Kowalski 공식 저장소](https://github.com/emilkowalski/skills)의 `skills/emil-design-eng`이며, 원본 커밋과 MIT 라이선스를 함께 보관합니다. 기존 apple-design은 같은 저장소의 별도 스킬입니다. v0.3.0의 패키징 검증은 여섯 스킬, 원본 라이선스, 기존 자산 보존을 확인합니다. 실제 UI 품질은 대상 프로젝트를 실행해 확인해야 합니다.

참고: [OpenAI 스킬 안내](https://learn.chatgpt.com/docs/build-skills), [스킬과 MCP 도구의 역할](https://developers.openai.com/plugins/concepts/skills).

2026-10-23 Windows 검증: `python -m unittest discover -s tests -p test_packaging.py -v` 3개 통과, 전체 패키지 빌드·ZIP 무결성 확인, 새 스킬의 로컬 설치본과 패키지 바이트 일치 확인. SKILL.md의 upstream Git blob은 `62ce902af8dd32c590ea7203e9ab2edb1d6ef81a`, LICENSE는 `57b46f1fd11dc62351ea548104a88aa3f659c11b`와 일치했습니다. 계정 업데이트는 기존 파일을 유지하는 5개 파일의 부분 ZIP으로 준비했고, 현재 계정의 매니페스트와 비교해 버전 외 메타데이터를 보존했습니다. 특정 웹 프로젝트의 UI 실행·화면 비교는 이번 설치 작업의 검증 대상이 아닙니다.
